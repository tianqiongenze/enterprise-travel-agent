# TechGroup Enterprise Travel Gateway API Developer Guide

## 1. Base Information

- Service: `techgroup-enterprise-travel-gateway`
- Base URL: `http://localhost:8080/api/v1/travel`
- Content-Type: `application/json`
- Runtime forward target: `${TRAVEL_RUNTIME_BASE_URL}/runtime/recommend`

## 2. Headers

### Request Headers

- `Content-Type: application/json`
- `X-Trace-Id` (optional): if absent, gateway auto-generates a UUID

### Runtime Internal Headers (added by gateway)

- `X-Internal-Client-Id`
- `X-Internal-Signature`
- `traceparent`

## 3. Endpoints

### `GET /health`

Health probe for liveness/readiness.

Response:

```json
{
  "status": "ok"
}
```

### `GET /policy/cache/stats`

Returns policy decision cache statistics used by dashboards.

Response:

```json
{
  "cacheSize": 12,
  "cacheHits": 205,
  "cacheMisses": 17,
  "cacheHitRatio": 0.923423
}
```

### `POST /recommend`

Validates policy, forwards request to Python runtime, mirrors audit to Pulsar (optional), and enriches `aiRationale`.

Request schema:

```json
{
  "tenantId": "tenant-a",
  "userId": "user-1001",
  "policyId": "policy-core.v1",
  "conversationId": "conv-0001",
  "idempotencyKey": "req-20260329-0001",
  "city": "Shanghai",
  "days": 3,
  "budget": 2600,
  "travelers": 2,
  "membershipTier": "gold",
  "preferences": ["food", "family", "museum"],
  "maxAgentSteps": 8,
  "maxToolCalls": 16,
  "allowedTools": ["hotel.search", "transport.search", "attraction.search"]
}
```

Response schema:

```json
{
  "traceId": "32b4f0b9-68f2-4b93-98d4-2c102d7c3f91",
  "aiRationale": "Your plan prefers low transfer cost and family-friendly attractions.",
  "hotelOptions": [],
  "transportOptions": [],
  "itinerary": [],
  "engagementRecommendations": [],
  "auditLogs": [],
  "a2aLogs": []
}
```

## 4. Validation and Policy Rules

- Required: `tenantId/userId/policyId/conversationId/idempotencyKey`
- Required: `city/days/budget/travelers/preferences`
- Required: `maxAgentSteps/maxToolCalls/allowedTools`
- `days`, `budget`, `travelers`, `maxAgentSteps`, `maxToolCalls` must be >= 1
- `allowedTools` must be a non-empty subset allowed by `membershipTier`

## 5. Error Model

All non-2xx responses follow the same payload contract:

```json
{
  "code": "POLICY_VIOLATION",
  "message": "allowedTools contains unsupported tool",
  "traceId": "trace-policy-001",
  "path": "/api/v1/travel/recommend",
  "timestamp": 1774785600000,
  "suggestion": "Adjust membership tier, allowedTools, or policy limits"
}
```

Field meanings:

- `code`: stable machine-readable error code for client branching.
- `message`: human-readable error reason.
- `traceId`: copied from `X-Trace-Id` if present, otherwise generated by gateway.
- `path`: request URI.
- `timestamp`: epoch milliseconds.
- `suggestion`: operator or caller remediation hint.

Error code matrix:

| HTTP | code | Trigger |
|---|---|---|
| `400` | `VALIDATION_ERROR` | Request body schema/constraints failed |
| `403` | `POLICY_VIOLATION` | Policy guard rejected tool/limit/tier/engine request |
| `503` | `DEPENDENCY_UNAVAILABLE` | Runtime/dependency temporary unavailable (`IllegalStateException`) |
| `500` | `INTERNAL_ERROR` | Unexpected server-side exception |

`400` example:

```json
{
  "code": "VALIDATION_ERROR",
  "message": "allowedTools: must not be null",
  "traceId": "trace-validation-001",
  "path": "/api/v1/travel/recommend",
  "timestamp": 1774785605000,
  "suggestion": "Check request schema and required fields"
}
```

`503` example:

```json
{
  "code": "DEPENDENCY_UNAVAILABLE",
  "message": "runtime response is empty",
  "traceId": "trace-runtime-001",
  "path": "/api/v1/travel/recommend",
  "timestamp": 1774785610000,
  "suggestion": "Retry with same idempotencyKey or route to fallback region"
}
```
