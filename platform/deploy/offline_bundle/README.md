# Offline Bundle

This directory stores offline artifacts generated by:

```bash
python3 -u platform/deploy/scripts/one_click_stack.py --project-root . --package-mode prepare --offline-bundle-dir platform/deploy/offline_bundle
```

Expected files:

- `images/*.tar`: Docker image archives
- `tools/<target>/kubectl(.exe)` and `tools/<target>/kind(.exe)`: offline K8s tools
- optional `tools/<target>/docker-*`: BYO Docker installers
- `artifacts.manifest.json`: SHA256 manifest used by offline validation

App images are prebuilt by `one_click_stack.py` before bundle packaging:

- `enterprise-travel-agent-api:local`
- `enterprise-travel-agent-gateway:local`
- `enterprise-travel-agent-web:local`

Run one-click in offline mode:

```bash
python3 -u platform/deploy/scripts/one_click_stack.py --project-root . --package-mode offline --offline-bundle-dir platform/deploy/offline_bundle --offline-strict
```
