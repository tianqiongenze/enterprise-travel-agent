# gRPC Contracts (v1)

This folder contains shared internal RPC contracts for hot paths.

## Proto Files

- `v1/common.proto`: shared context and common entities
- `v1/runtime.proto`: Gateway -> Runtime recommendation RPC
- `v1/policy.proto`: Gateway/Runtime -> Go Policy evaluate RPC
- `v1/ranker.proto`: Runtime -> Go Ranker score RPC

## Codegen Outputs

- Python: `services/techgroup-enterprise-travel-runtime/src/travel_agent/grpc/generated/v1`
- Go policy: `services/techgroup-enterprise-travel-policy-go/internal/grpcgen/v1`
- Go ranker: `services/techgroup-enterprise-travel-ranker-go/internal/grpcgen/v1`
- Java gateway: generated by Maven into `target/generated-sources/protobuf`

## Regenerate

```powershell
python scripts/generate_grpc_stubs.py
```

Drift check (used by CI):

```powershell
python scripts/check_grpc_stub_drift.py
```

For Java stubs:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/generate_grpc_java_stubs.ps1
```
