# 公开分享版风格规范

## 1. 内容特色定位

- 主题：企业级智能旅游推荐智能体（教学+产业双场景）
- 特色：Spring AI Alibaba + MCP + Skills + Registry + A2A 一体化
- 演示重点：可运行、可观测、可扩展、可治理

## 2. 视觉风格建议

- 主色渐变：
  - 深蓝 `#0F172A` -> 靛蓝 `#1D4ED8` -> 青蓝 `#06B6D4`
- 强调色：
  - 橙金 `#F59E0B`
  - 青绿 `#10B981`
- 字体层次：
  - 标题：粗体高对比
  - 正文：中等字重，保证投影可读性

## 3. 图文并茂标准

- 每章至少 1 张架构图或时序图
- 每 2~3 页至少 1 个图表（矩阵、柱状、流程）
- 每个技术点都配“落地代码路径 + 可验证命令”

推荐图表模板：

- 架构：分层框架图（网关/运行时/注册中心/工具）
- 性能：压测结果柱状图（avg/p95/p99）
- 选型：加权评分矩阵热力表
- 运维：上线前检查清单看板

## 4. 公开分享质量门槛

- 结论先行（前 3 页明确价值）
- 中段有真实代码/日志证据
- 结尾给路线图、风险与演进计划

额外要求（本项目适配）：

- 明确区分“本地压测结论”与“分布式容量认证结论”
- 所有容量数字必须附测试场景与参数
- 对外口径遵循可验证原则（可复现命令 + 报告位置）
